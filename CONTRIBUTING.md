# Contributing

Thanks for helping improve Canvas Organizer.

1. Create a focused branch from `main`.
2. Never use real Canvas, Google, school, or student data in fixtures, screenshots, issues, or commits.
3. Run `npm test` and `npm run check` on Node.js 22 or newer.
4. Explain behavioral and security changes in the pull request.

Bug reports should include the operating system, Pi version, Canvas access mode (browser, API token, or iCalendar), the exact error text, and sanitized reproduction steps.
